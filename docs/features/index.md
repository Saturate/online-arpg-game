# Feature docs

One file per feature, each the single place that explains it: what it does, why it works that way, where the code lives, and what is still open. Cross-cutting decisions (networking, prediction, input, browser safety, look, operations) are in [DECISIONS.md](../../DECISIONS.md); the original design brief is [SPEC.md](../../SPEC.md).
